## Goal

`packages/cli` exists in the pnpm workspace and ships an `ef` binary whose
`ef replay <dump.jsonl> --digest [--reducer <module>]` subcommand replays a dumped event
log through the pure replay core from `packages/protocol` (E0-T03) and prints the
canonical SHA-256 state digest — one lowercase hex line on stdout, exit 0 — making it the
citation tool every later task's Verification log uses for stream-layer claims. Any
malformed, truncated, or envelope-violating dump exits nonzero with a diagnostic on
stderr naming the offending 1-based line number where one exists (some failures — e.g.
an empty file or an unreadable path — have no line to name), and prints **no digest**. The Makefile's
`_v-replay-determinism` recipe (currently written to fail red the moment `packages/cli`
appears) goes live: it replays a committed golden log twice through two separate `ef`
process invocations and compares the digests byte-for-byte, failing nonzero on any
difference, and `make verify-E0-T04` composes it with the standard TypeScript gates.

## Context

E0-T03 froze the protocol contract — event envelope, canonical JSON encoding, opaque
lexicographic offsets, SHA-256 state digests, and a pure `replay(events, reducer)` core —
as a library. This task gives that library a mouth. The evidence doctrine in `AGENTS.md`
makes `ef replay <dump> --digest` the stream layer's citation currency: builders cite
`event-log path + digest`, critics re-derive the digest themselves from the cited dump,
and equality claims become digest comparisons rather than eyeballs. Nothing downstream
(E0-T05's server, E0-T09's conformance suite, E0-T12's `ef bisect`, the E0-T13 capstone's
two-terminal digest match) can be *proven* without this tool existing and being trusted.

The `Makefile` was built to force this task's hand: `_v-replay-determinism` (Makefile,
verify section) guards on `packages/cli` existing and **fails red by design** once it
does, until this task wires the real double-replay comparison. The recipe contract frozen
by E0-T02 applies: real run, loud skip, or red — never a faked pass, and
`tools/verify/self_check.sh` (`_v-meta`) polices the edited recipe text.

Contract frozen here: the CLI's digest output format — exactly one line on stdout,
lowercase hex SHA-256, nothing else on stdout in `--digest` mode — is frozen, because
scripts, Makefile recipes, and critics parse it forever after. The golden log committed
here (`evidence/golden.jsonl` + `evidence/golden.digest`) becomes a permanent regression
fixture; changing the protocol later must be caught by this digest going stale.

Dump format: the input is JSONL — one canonical-JSON event envelope per line, in offset
order, exactly what a stream dump produces. The `--reducer <module>` flag loads a reducer
module by path; without it, `ef replay` uses the deterministic default/test reducer
shipped in `packages/protocol` (whichever E0-T03 exported for this purpose — the golden
log is built against it).

## Deliverables

- `packages/cli/` workspace package: `package.json` with `"bin": {"ef": ...}`, wired into
  the root workspace so `pnpm build` produces a runnable `ef` and all E0-T01 gates
  (format/lint/typecheck/test/build) cover it.
- `ef replay <dump.jsonl> --digest [--reducer <module>]`: streams the dump line by line,
  validates each line against the frozen envelope (canonical JSON, offset monotonicity),
  folds through `packages/protocol`'s replay core, prints the canonical SHA-256 state
  digest. Exit codes: 0 = digest printed; nonzero for unreadable file, malformed JSON,
  non-canonical encoding, envelope violation, out-of-order/duplicate offsets, truncated
  final line, unloadable reducer, or empty/missing path — each with a stderr diagnostic
  citing the 1-based line number where applicable.
- `ef replay` without `--digest` (or `ef` with no/unknown subcommand): usage on stderr,
  nonzero exit — no silent default behavior.
- Committed golden fixture: `E0-T04-ef-replay-digest/evidence/golden.jsonl` (a
  representative multi-event log valid under the E0-T03 envelope) and
  `evidence/golden.digest` (its frozen expected digest, produced once and committed —
  never regenerated by the check that consumes it).
- Committed prefix-digest table: `evidence/golden.prefix-digests` — one line per k
  (`k<TAB><digest>`) giving the digest of `golden.jsonl` truncated to its first k
  records, for every k from 1 to the record count. Produced once and committed, never
  regenerated by the checks that consume it; this is the fixture the one-byte-sensitivity
  localization check (criterion 4) and adversarial angle 1 replay against.
- Committed alternate reducer: `evidence/alt-reducer.mjs` — a deterministic reducer
  module, distinct from the `packages/protocol` default, committed at that path so the
  `--reducer <path>` flag's module-loading-by-path behavior is exercised against a real
  on-disk file (not an in-process import or a reducer defined inline in a test). This is
  the artifact criterion 5 loads.
- Committed rejection corpus: `evidence/fuzz/` — at minimum, with each case tagged by
  whether its diagnostic must cite a line number:
  - Line-anchored (stderr diagnostic must cite the correct 1-based line number N of the
    offending record): invalid JSON line, non-canonical key order, out-of-order offsets,
    duplicate offset, missing envelope field, wrong-type field, truncated-mid-record.
  - Non-anchored (nonzero exit + stderr diagnostic required; no line number required):
    empty file, missing/unreadable path.
  Each case's expected outcome (exit code, empty stdout, and — for line-anchored cases —
  the cited line number) is asserted by a committed test.
- Makefile: `_v-replay-determinism` rewritten to run `ef replay` on the golden log
  **twice as separate process invocations**, compare the two digests to each other AND to
  `evidence/golden.digest`, exit nonzero on any mismatch; `verify-E0-T04` per-task target
  composed from `_v-fmt _v-lint _v-typecheck _v-test _v-build _v-replay-determinism`,
  added to `verify-all`, passing `_v-meta` / `tools/verify/self_check.sh`.
- Unit/integration tests in `packages/cli`: digest correctness against the golden pair,
  every fuzz-corpus case exits nonzero without printing a digest line, `--reducer`
  loading (a different reducer module yields a different digest on the same log),
  one-byte sensitivity (flip one byte of one record → digest changes and/or parse fails).

- [ ] Every file in `evidence/fuzz/` fed to `ef replay <file> --digest` exits nonzero

      names the correct 1-based line number. Evidence: a committed test iterating the
      corpus and asserting `stdout.length === 0` for every case, green under `pnpm test`.
- [ ] One-byte sensitivity: flipping any single byte inside a record's payload of a copy
      of `evidence/golden.jsonl` either fails parsing (nonzero exit) or yields a digest
      different from `evidence/golden.digest`. Digest scope, stated once so this
      criterion and adversarial angle 1 agree: under the E0-T03 contract the digest is
      SHA-256 over the canonically-encoded **reduced state** — envelope/offset bytes do
      **not** feed the digest. Therefore a flip in an envelope/offset byte must either
      fail validation (nonzero exit, no digest) or, if the mutated line remains a valid
      canonical envelope with monotone offsets, is digest-neutral by contract — the
      golden digest with exit 0 is the *expected* outcome there, not a failure.
      Localization (the fold proof): for a
      mutation at record N that still parses, replay successive prefixes of the
      **mutated** file (records 1..k for k = 1..len) and compare each digest against the
      committed `evidence/golden.prefix-digests` table — the first k at which the digest
      diverges from the table must be exactly k = N (divergence at any k < N, or no
      divergence at k = N, fails). This is what makes the digest a fold over records and
      keeps E0-T12's `ef bisect` viable. Evidence: committed test + the mutation script's
      transcript in the Verification log.
- [ ] `--reducer` pointed at the committed alternate reducer
      (`evidence/alt-reducer.mjs`, per Deliverables) — loaded via the
      `--reducer <path>` CLI flag on the `ef` command line, not via an in-process
      import — produces a byte-identical digest for `golden.jsonl` across two separate
      fresh-process invocations of `ef`, and that digest differs from
      `evidence/golden.digest`; pointing `--reducer` at a nonexistent module exits
      nonzero. Evidence: committed test.
- [ ] Usage paths are pinned, not just executed: `ef` (no subcommand), `ef bogus`
      (unknown subcommand), and `ef replay evidence/golden.jsonl` (no `--digest`) each
      exit nonzero with stdout exactly 0 bytes and nonempty stderr matching a usage
      pattern (e.g. `/usage/i` or an explicit `Usage:` line). Evidence: a committed test
      asserting exit code, `stdout.length === 0`, and the stderr pattern for all three
      invocations, green under `pnpm test`.
- [ ] `bash tools/verify/self_check.sh` (`make _v-meta`) exits 0 after the Makefile edits
      — the rewritten `_v-replay-determinism` and new `verify-E0-T04` contain no
      greenwash escapes, and `make verify-list` shows E0-T04 covered.
- [ ] Replay (browser) layer: N/A — CLI-only task, no browser-reaching surface; evidence
      is stream-layer per AGENTS.md, declared explicitly in the claim.

## Adversarial verification

Attack angles for the hostile critic. Run each with your own inputs, never the builder's;
any single success refutes.

1. **Sensitivity proof of the measuring apparatus (mandatory).** Write your own mutation
   script: for a sweep of positions (not just the builder's chosen one), flip one byte
   **inside a record's payload** of `golden.jsonl` and run `ef replay --digest`.
   Refutation: any payload mutation that still yields the golden digest with exit 0 —
   the apparatus can't see corruption, so every downstream digest claim in this repo is
   void. Sweep envelope/offset bytes separately, under criterion 4's stated digest
   scope (digests cover reduced state only; envelope bytes are digest-neutral): each
   such flip must either exit nonzero with no digest, or leave a line that is still a
   valid canonical envelope with monotone offsets — in which case the golden digest
   with exit 0 is the contractually expected outcome, not a refutation. Refutation for
   the envelope sweep: an *invalid* mutation (malformed JSON, non-canonical encoding,
   broken offset monotonicity, missing/wrong-type field) that exits 0. Also attack
   localization with your own
   mutations: pick a record N, apply a still-parsing one-byte mutation, then replay
   successive prefixes of the **mutated** file (records 1..k for k = 1..len) and compare
   each digest against the committed `evidence/golden.prefix-digests` table. Refutation:
   the first divergence from the table appears at any k < N, or fails to appear at k = N
   — either way the digest is not a fold over records and the `ef bisect` plan (E0-T12)
   is built on sand. (Note: comparing the *unmutated* prefix 1..N-1 proves nothing — its
   bytes are untouched; only prefixes of the mutated file, including record N and beyond,
   can refute.)
2. **Self-licking golden.** Inspect git history and the Makefile recipe: is
   `evidence/golden.digest` ever (re)generated by the same code path that the check
   compares against, at check time? Delete the digest file and run
   `make _v-replay-determinism` — it must fail red, not regenerate-and-pass. Apply the
   same attack to `evidence/golden.prefix-digests`: delete it and run the localization
   test (criterion 4's check) — it must fail red, not regenerate-and-pass; inspect git
   history and the test code for any code path that writes or recomputes the table at
   check time. A recipe or test that computes its own expectation refutes the gate.
3. **Two-invocation honesty.** Read the rewritten `_v-replay-determinism` recipe text: it
   must spawn `ef` twice as separate processes and compare outputs. Sabotage it in a
   scratch worktree — make the replay core nondeterministic (e.g. inject
   `Math.random()`/`Date.now()`/object-key-iteration dependence into state building) —
   and the recipe must go red. If it stays green, the "double replay" is one replay
   printed twice, and the gate is theater.
4. **Fuzz beyond the corpus.** Generate your own malformed dumps: NUL bytes, CRLF line
   endings, a BOM, duplicate JSON keys, unicode-escaped vs literal characters
   (canonical-JSON discrimination), a 0-byte final line vs missing trailing newline,
   offsets that sort differently lexicographic-vs-numeric, a syntactically valid record
   after an invalid one (must still fail — no skip-and-continue). Refutation: any invalid
   input that exits 0, or — worse — prints a digest. Also: a *valid* dump whose digest
   differs between `ef replay` and a direct call into `packages/protocol`'s replay core
   on the same events (differential check — the CLI must be a thin mouth, not a second
   implementation).
5. **Cold-clone + env hunt.** Run the acceptance commands only via
   `tools/verify/cold_clone.sh` with `NODE_OPTIONS`/`NODE_ENV`/`npm_config_*` scrubbed.
   Then grep the diff for env reads, locale/timezone-sensitive formatting
   (`toLocaleString`, `Intl`), and machine-dependent paths leaking into state or digest.
   Refutation: golden digest differs across cwd, `TZ=UTC` vs `TZ=Pacific/Kiritimati`, or
   `LANG=C` vs `LANG=en_US.UTF-8` runs.
6. **stdout purity.** In `--digest` mode, assert stdout is exactly `<64 hex chars>\n` —
   pipe through `wc -c` (must be 65) and a hex regex. Any banner, warning, or progress
   noise on stdout refutes the frozen output contract that Makefile recipes and future
   critics parse. Failure modes too: feed every file in `evidence/fuzz/` (and your own
   angle-4 inputs) to `ef replay <file> --digest` and assert stdout through `wc -c` is
   exactly 0 on every nonzero exit — any bytes on stdout in an error case refute, not
   just digest-shaped ones.
7. **Sabotage the tests.** In a scratch worktree, break the digest (e.g. truncate the
   hash, digest the non-canonical encoding, skip the last record) and run `pnpm test` +
   `make verify-E0-T04`. Any break that stays green refutes the suite. Check the diff for
   `.skip`/`.todo`/inline lint disables while you're in there.
8. **Coverage.** Hold the recorded/claimed final run against the diff: `--reducer`
   loading, every distinct error path (unreadable file, bad reducer, each envelope
   violation class), and the usage/no-subcommand path must each have been executed by a
   test or transcript. Unexecuted diff is unproven or dead — builder chooses which, you
   enforce it.
