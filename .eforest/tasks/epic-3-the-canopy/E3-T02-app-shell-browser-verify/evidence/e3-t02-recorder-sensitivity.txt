The control reaches the exact command slot occupied by
`browser-close.js` in the production workflow. Each sabotage executes the
real walkthrough event handler from the same normalized expression file used
by `playwright-cli`, observes its expected rejection, then feeds the same
failure class to the production publish guard. The normalizer compiles the
formatter-terminated source and removes its trailing semicolon before the
browser opens. In all three cases the guard exits nonzero before the supplied
browser-close/upload stand-in is invoked. Failure cleanup in
`record-e3-t02.sh` uses raw
`playwright-cli close`, which closes the unfinished browser without invoking
the Replay lifecycle close/transcode/upload script.

The real walkthrough also tracks Replay Chromium's asynchronous JavaScript
source-map fetches and requires two consecutive quiescent checks before the
logout navigation. This prevents navigation from manufacturing an
`ERR_ABORTED` request failure while preserving the invariant that every
observed `requestfailed` event rejects the recording.
